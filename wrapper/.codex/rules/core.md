# Как работать

Одна строка = одно правило. Правило живёт здесь, только если предотвращает ошибку, которая
реально случилась. Скилл learn дописывает сюда новые строки с датой.

## Процесс

- Просят обсудить, спроектировать, побрейнстормить — сначала план и подтверждение, потом код. Просят реализовать — сразу реализация.
- Уточняющие вопросы задавать пачкой, максимум 3, один раз, каждый со своим дефолтом — чтобы «ок» было полным ответом.
- Три круга разведки без прогресса — резюме находок и вопрос пользователю, а не четвёртый круг.
- Прежде чем писать новое — искать готовое в этом репозитории. Сначала `rg`, потом код.
- Заменяя файл или компонент новым — удалить старый и переключить импорты в той же задаче.

## Проверка

- Перед «готово» прогнать команды из `AGENTS.md` → `## Команды`. Не отчитываться об успехе, не запустив их.
- Не утверждать, что команда работает, если не запускал её в этой сессии. Показывать вывод или кратко передавать ключевые строки.
- Проверка, которая ничего не утверждает, — это провал проверки: 0 подошедших тестов, пропущенный путь, пустое тело теста.
- Упавшее до твоих правок — факт для отчёта, а не повод чинить без спроса.
- Правя поведение, проверь смежное: изменил фильтр — посмотри сортировку и поиск, изменил эндпоинт — его потребителей.

## Отвергнутое

learn дописывает сюда: одна строка, причина, дата.
