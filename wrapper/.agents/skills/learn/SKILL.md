# learn

Работает в главной сессии: входные данные — её транскрипт. Сказано `audit` — сразу к шагу 4.

## 1. Собрать — только эта сессия, максимум 5

Урок проходит, только если это устойчивое утверждение, меняющее будущее поведение. Смысловое,
не эпизодическое: «тесты этого репозитория молча проходят без `DATABASE_URL`» — да; «сегодня
упала сборка» — нет.

Отбросить: разовые факты, всё с уверенностью ниже примерно 80%, и то, что уже есть в памяти или
правилах и не противоречит им. Для каждого кандидата сформулировать: что я сделал → чего на
самом деле хотели → правило.

## 2. Разложить — ровно один адрес на урок

| Урок | Куда | В какой форме |
|---|---|---|
| факт об этом проекте: ловушка, граница системы, почему выбрано X | Serena, если доступна | по `.codex/rules/memory.md`, строка в `MEMORY` тем же ходом |
| инвариант работы, который агент нарушил | строка в `.codex/rules/<стек>.md`, либо `core.md`, если стек ни при чём | одна повелительная строка + дата |
| нарушение, которое способен поймать парсер | правило линтера или скрипт | сообщение об ошибке объясняет замену |
| многошаговая процедура, которую будем повторять | новый скилл `.agents/skills/<имя>/SKILL.md` | см. «Предложить скилл» ниже |
| подход, который пользователь отверг | `.codex/rules/core.md` → `## Отвергнутое` | одна строка: что и почему, с датой |
| существующее правило или память оказались неверны | тот же файл — заменить строку, а не дописать вторую | одна строка + дата |
| команда из `AGENTS.md` работает не так, как записано | `AGENTS.md` → `## Команды` | сначала перезапустить команду, потом исправить запись |
| всё остальное | никуда | отбросить |

`AGENTS.md` — не адрес ни для чего, кроме `## Команды` и `## Нерушимое`. Урок, попадающий в два
места, кладётся только в более сильное. Дату брать из системной даты или `date +%F`, не угадывать.

Если Serena недоступна, не создавать псевдо-память файлами. Проектные факты без Serena либо
попадают в правило, если меняют поведение агента, либо не записываются.

## 3. Предложить скилл — когда процедура повторится

Процедура тянет на скилл, если у неё несколько шагов, она уже повторялась и её легко сделать не в
том порядке. Предлагать так:

- имя папки = глагольное, в kebab-case: `.agents/skills/release-ios/SKILL.md`;
- `description` говорит когда вызывать — от третьего лица, с буквальными фразами-триггерами;
- тело — до 100 строк, шагами, с реальными командами;
- длинные справочники выносить в соседний файл рядом со `SKILL.md`.

Не предлагать скилл там, где хватает одной строки в правилах.

## 4. Предложить, не писать молча

Напечатать список: `N. [адрес] изменение одной строкой`. Применить только те номера, которые
назовут; «все» — допустимый ответ; молчание не применяет ничего. Два источника противоречат —
показать обе стороны и дать решить пользователю. Записывать нечего — сказать это одной строкой.

## 5. Аудит

Запускать, когда сказали `audit`, и всегда, если выполняется хотя бы одно измеримое условие:

- суммарно в `.codex/rules/` больше примерно 90 строк-правил;
- памятей Serena больше восьми.

Что делает аудит:

- два правила противоречат — проигравшее удалить целиком;
- правило, чья причина исчезла из кода, удалить;
- правила про одно и то же слить в одно;
- памяти сверх восьми слить; память, которую не пролистать, разрезать на карточку и `-details`;
- памяти, которых нет в `MEMORY`, дописать в индекс.

Отчитаться о том, что удалено. Удаление и есть смысл аудита.
