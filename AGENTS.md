# HackAlem AI contractor recommender API

Проект: API для хакатон-задачи #79-lite «умный подбор подрядчиков». Сервис принимает параметры
event-заказа и возвращает до 3 карточек подрядчиков с конкретным объяснением по бюджету,
дате, формату, языку, длительности и смыслу описания.

Всегда используй OpenAI developer documentation MCP server, если нужно работать с OpenAI API,
plugins, ChatGPT, Codex или их документацией.

## Источники

- ТЗ: `HackAlem AI_ Хакатон-задача_ умный подбор подрядчиков.docx`
- Данные: `hackathon dataset anonymized.csv`
- Preview: `hackathon dataset preview.html`

## Инварианты задачи

- Подрядчик, занятый на дату запроса, не попадает в выдачу.
- Категории в CSV могут быть составными через `|`; запрос по одной категории должен матчить часть составной категории.
- Тот же запрос даёт тот же порядок карточек.
- Возвращать максимум 3 карточки.
- Объяснение не должно быть общей фразой. В нём должны быть конкретные причины: бюджет, формат, язык, длительность, дата, смысл описания.
- Если подходящих меньше трёх, явно сказать сколько есть и почему меньше.
- Три исхода различимы для пользователя: подобрали / в городе нет категории / кандидаты есть, но отфильтрованы условиями.
- Декабрьская плотная занятость — ожидаемое свойство датасета, а не баг.
- Не дообучать модель на 66 записях; embeddings/LLM через API допустимы, но должен быть fallback без API.
- Синтетические профили допустимы только с `synthetic: true`; в демо должно быть видно, где настоящий профиль, а где синтетический.

## Данные

- CSV: 66 строк, 13 колонок.
- Города: Алматы — 50, Астана — 15, Зарубежье — 1.
- Плотные категории: Ведущий — 15, Фотограф — 12, Банкетный зал/площадки — 8.
- Редкие категории: Флорист, Декоратор, Подарки и сувениры, Ведущий церемонии, Фото и видеобудки, Отель, Инструменталист — около 3 профилей.
- Флаги качества: `synthetic` — 13, `city_imputed` — 8, `price_imputed` — 18.
- `max_hours = null` означает, что работа не привязана к присутствию на площадке.

## Первые демо-сценарии

- Плотная категория: Алматы, `2026-10-15`, корпоратив, Ведущий, бюджет около 900000, русский.
- Та же категория в декабре: Алматы, `2026-12-20`, Ведущий — должно измениться из-за занятости.
- Редкая категория: Астана, Флорист или Инструменталист.
- Пустой результат: город/категория или бюджет, где кандидаты есть, но условия отсекают всех.
