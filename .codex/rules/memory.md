# Память проекта

Одно хранилище — Serena (`.serena/memories/`), если MCP-сервер Serena доступен.

Если Serena не подключена, не имитируй память файлами: работай от `AGENTS.md`, правил и кода.

## Что записывать

- Неочевидный инвариант, принятое решение и его причина, ловушка, граница между системами, поведение внешнего сервиса.
- Тест на допуск: это можно узнать, прочитав код, git log или README? Тогда не записывать.
- Не записывать структуру кода, списки файлов, пересказ диффа или то, что уже есть в `AGENTS.md`.

## Как записывать

- Сначала `read_memory("MEMORY")`.
- Есть релевантная память — обновить её. Две памяти на одну тему — это баг.
- Имя — kebab-case по паттерну или архитектуре.
- Настоящее время, текущее состояние. Даты только абсолютные.
- Доменные термины — на языке ТЗ.
