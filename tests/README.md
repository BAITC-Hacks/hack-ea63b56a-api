# Проверки исходного датасета

Запуск из корня проекта в PowerShell 7, без дополнительных зависимостей:

```powershell
pwsh -NoProfile -File tests/dataset.tests.ps1
```

Шесть тестов проверяют:

1. Схему CSV, 66 профилей и уникальность идентификаторов подрядчиков.
2. Корректность дат занятости и диапазон `2026-09-23` — `2026-12-31`.
3. Явные значения `True`/`False` для флагов `synthetic`, `city_imputed` и `price_imputed` каждого подрядчика.
4. Числовые неотрицательные цены и положительные ограничения по часам; пустое `max_hours` допустимо.

5. Непустые категории, форматы и языки, включая каждый элемент списка через символ "|".
6. Календари плотного демо: из 10 ведущих Алматы свободны 8 на 15 октября и 2 на 20 декабря. Это доступность по дате до проверки бюджета, формата и языка.

При ошибке команда завершается с кодом 1. Это проверки исходных данных;
проверки приложения и их отчёты описаны ниже.

## Проверки приложения и сверка требований

В эту ветку добавлены копии файлов тестирования из main:

- `recommendation-scenarios.spec.cjs` — 7 сценариев фильтрации, параллельных запросов и недостоверных объяснений ИИ.
- `site-scenarios.mjs` — повторный запрос, восстановление после HTTP 503 и безопасный вывод HTML из ответа.
- [AI-SCENARIOS-REPORT.md](AI-SCENARIOS-REPORT.md) — воспроизведение ошибок и результаты прогонов.
- [REQUIREMENTS-REVIEW.md](REQUIREMENTS-REVIEW.md) — сверка с ТЗ и критериями жюри.

**В nura пока нет backend/ и frontend/.** Поэтому эти файлы здесь сохраняют
сценарии тестирования приложения из main; они не запускаются самостоятельно
в этой рабочей копии. Доступный здесь тест датасета выше проходит 6/6.
История nura и исходный CSV сохранены, код приложения в эту ветку не переносился.

Для запуска проверок приложения используйте отдельную рабочую копию проверенного
коммита [9b79505](https://github.com/BAITC-Hacks/hack-ea63b56a-api/tree/9b79505b13c7de1b7917ba1e7a0405c3a8d6c9b4):

```sh
git fetch origin
git worktree add --detach ../hackalem-test-run 9b79505b13c7de1b7917ba1e7a0405c3a8d6c9b4
cd ../hackalem-test-run
npm --prefix backend ci
npm --prefix backend test -- --runTestsByPath ../tests/recommendation-scenarios.spec.cjs
```

Нужен Node.js 22.13+. Дополнительные команды браузерного запуска находятся
в tests/README.md рабочей копии main; требуется работающий сайт и Chromium.

Последний полный прогон приложения на базе `05be10f`: backend **75 PASS / 4 FAIL**,
frontend **18/18**, линтеры и сборки прошли. Четыре проверки намеренно не скрывают
обнаруженные проблемы: три недостоверных AI-утверждения и расхождение строгого
ограничения бюджета с новой выдачей альтернатив. Это результат тестирования;
исправления приложения в данный коммит не входят.
