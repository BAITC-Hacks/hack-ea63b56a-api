# Проверка проекта — 23 сентября 2026

Работа выполнена тремя субагентами под контролем основного агента: тестировщик,
критик дизайна/кода/функционала, разработчик исправлений. После первого аудита проведена
повторная проверка исправлений.

## Исправлено

- Календарная дата проверяется строго: timestamp и несуществующая дата отклоняются.
- Парсер понимает «Астане», «свадьбу», бюджет 1 ₸, тыс./млн и несколько языков.
- Все указанные языки обязательны для подрядчика; в форме доступны чекбоксы.
- Каждое предложение изменить бюджет, длительность, язык или дату проверяется полным
  отбором и содержит число доступных кандидатов. Если одного изменения недостаточно,
  бесполезная подсказка не показывается. Альтернативная дата ищется в ближайшие 30 дней.
- Маленькая категория не выдаётся за массовое исключение кандидатов.
- Лексический fallback учитывает простые отрицательные пожелания и словоформы.
- Условия полученного результата сохраняются отдельно от редактируемой формы.
- Новый самостоятельный запрос не наследует старые язык, часы и бюджет.
- Добавлены повтор запроса после ошибки, прокрутка к редактированию, перенос карточки
  на узком экране и видимый фокус клавиатуры.
- Уточнены требования Node.js 22+ и отдельное окружение Next.js.
- Вызовы OpenAI ограничены по времени и длине ответа; автоматические повторы отключены.
  Ошибки логируются без сырых сообщений API. Неполный ответ, неверные ID или невалидный
  JSON приводят к локальному fallback.

## Проверки

- 30 из 30 тестов прошли, три набора тестов; API lint также прошёл после добавления SDK mock.
- Автотесты используют реальные 66 профилей и искусственные граничные примеры.
- Проверены занятость, смена даты, составные категории, флаги качества, пустые результаты,
  минимальный достаточный бюджет, несколько языков и детерминизм.
- OpenAI проверяется через изолированный SDK mock; платных запросов нет.
- Общий lint и production-сборка прошли.

## Ограничения проверки

- Визуальный браузерный прогон недоступен: инструмент вернул пустой список браузеров.
  Дизайн и взаимодействия проверены по исходникам, а не по скриншотам.
- Настоящие ответы OpenAI и доступность модели для аккаунта не проверялись.
- Семантическое ранжирование остаётся локальной лексической эвристикой, а не полноценным
  embedding-поиском. AI используется для извлечения параметров и текста объяснений.
- Разговорное продолжение уточнения и качество всех возможных русских словоформ требуют
  дальнейшего UX-прогона; текущие уточнения заполняются через ручную форму.
